# Book Catalog Implementation Plan

**Goal:** 승인된 시안대로 60권 단일 HTML 카탈로그를 구현하고 앱 브라우저에서 검증한다.
**Architecture:** 표준 라이브러리 크롤러가 CSV와 HTML 내 JSON을 함께 갱신한다.
HTML은 내장 CSS/JS로 카드, 그래프, 정렬, 필터를 렌더링한다.
**Tech Stack:** Python 3.9+, HTML/CSS/JavaScript.
**Spec:** ../specs/2026-10-08-catalog-design.md

## Constraints
- 첫 3페이지, robots.txt 먼저 확인, 페이지 사이 최소 1초.
- 외부 JS/CSS 패키지 없이 index.html 하나로 표시. 표지는 HTTPS 원본 이미지.

## Review Focus
- 상대 표지 주소를 페이지 URL 기준으로 절대 주소 변환.
- 제목의 HTML 문자를 textContent로 처리하고 JSON의 < 문자를 이스케이프.
- 가격 구간 경계 및 필터 결과 합계 일치.
- 이미지 실패 시 대체 문구, 긴 제목 줄바꿈.
- 작은 화면에서 가로 넘침 없이 조작 가능.

## Tasks
- [x] crawl_books.py: image_url 수집, CSV와 HTML JSON 갱신. 실행 후 60개 URL 확인.
- [x] index.html: 시안 색상/간격/카드/그래프 및 정렬/필터 구현.
- [x] README.md: 필드와 사용 방법 갱신.
- [x] 앱 브라우저: 60개 표지 로드, 그래프 합계, 양방향 가격 정렬, 1~5점 필터 확인.
- [x] 앱 브라우저: 모바일 레이아웃 확인 후 기본 화면 복원, 시안과 스크린샷 비교.
