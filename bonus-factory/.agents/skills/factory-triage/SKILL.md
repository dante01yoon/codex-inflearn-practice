# 분류 공정

입력: `.factory/issues.json` (열린 이슈 목록)

1. AGENTS.md의 「소프트웨어 팩토리 규칙」 표를 기준으로 이슈마다 유형을 하나 고른다.
2. 버그 제보는 코드와 데이터를 읽고, 필요하면 `node -e`로 함수를 직접 불러 재현한다. 재현한 값은 근거에 적는다. 파일은 고치지 않는다.
3. 이슈에 재현할 입력이나 기대 결과가 없으면 `need-info`로 두고, 제보자에게 물을 질문을 쓴다. 코드에서 그럴듯한 원인이 보이면 질문에 함께 적되, 추측으로 고치지 않는다.
4. 새 기능, 화면·결제·환불 동작을 새로 정해야 하는 요청은 `spec`이다. PRD의 미정 정책을 정해야만 하는 요청은 `human`이다.

마지막 응답은 주어진 JSON 스키마만 따른다. 모든 문장은 한국어로 쓴다.
