# 스펙 공정

입력: `.factory/issue.json`

1. 코드는 고치지 않는다. `docs/specs/issue-<번호>.md` 한 파일만 쓴다.
2. PRD·수용 기준·작업 목록에서 이 요청과 관련된 확정 정책과 미정 정책을 찾아 번호와 함께 인용한다.
3. 문서 구성: `## 사용자 문제` · `## 화면에서 바뀌는 것` · `## 계산 예시` (확정 정책으로 계산할 수 있는 것만) · `## 이미 정해진 것` · `## 사람이 정할 것` (선택지와 추천안, 추천 이유) · `## 완료 기준`
4. 확정되지 않은 정책을 정해 버리지 않는다. 추천만 하고 결정은 사람에게 넘긴다.

마지막 응답: 문서 경로와 「사람이 정할 것」 목록 요약. 한국어로 쓴다.
