# 섹션 15 보강 4 — 하네스를 화면으로 확인하기

같은 화면을 두 폴더에 넣고, 같은 부탁("환불 금액 1,500원을 1,000원으로 바꿔줘")을 보낸 뒤 결과를 비교합니다.

1. 하네스 있음: `sec15-harness/after-lesson5`를 복사한 폴더에 `demo/`를 넣습니다. `node demo/server.mjs` → http://127.0.0.1:4174
2. 하네스 없음: `ev-booking-start`를 복사한 뒤 `AGENTS.md`와 `.specify`를 지운 폴더에 `demo/`를 넣습니다. `demo/server.mjs`의 4174를 4175로 바꾸고 실행합니다.
3. 두 폴더 모두 `git init && git add -A && git commit`으로 시작 지점을 만듭니다. 화면의 "tests 폴더" 칸이 이 커밋과 비교합니다.
4. 앱에서 각 폴더에 같은 부탁을 보냅니다. 끝나면 서버를 다시 실행하고 화면을 새로고침하세요(테스트는 서버 시작 때 실행됩니다).
