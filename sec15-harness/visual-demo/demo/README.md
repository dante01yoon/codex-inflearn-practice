# 하네스 수업 시연

실행: 프로젝트 루트에서 `node demo/server.mjs` (Node.js 24, 기존 node_modules 사용).
주소: http://127.0.0.1:4174
종료: 실행한 터미널에서 Ctrl+C.

- 추가 설치 없이 Node 기본 HTTP 서버와 HTML로 실행한다. 외부 배포하지 않는다.
- 환불 표는 `src/rules/refund.ts`의 기존 순수 함수를 호출한다. AC-07-1~3의 경계 사례를 표시하며 실제 환불을 실행하지 않는다.
- 기존 Vitest 규칙 테스트를 서버 시작 시 한 번 실행한다. JSON 결과는 임시 폴더에 저장한다. 테스트 실행 시각을 표시하며 재실행하려면 서버를 재시작한다.
- 상태 새로고침은 tests 폴더를 HEAD와 비교한다. 스테이징·작업 트리·미추적 파일 변경을 포함한다. Git 조회 실패를 변경 없음으로 표시하지 않는다.
- 새 테스트를 작성하거나 기존 테스트·규칙·훅을 수정하지 않았다. 예약 앱의 T-01/C-10 전체 기술 구성 확정을 의미하지 않는다.

## 검증 기록

이번 요청의 시연 도구에 한정한다.

| 확인 | 상태 | 근거 |
|---|---|---|
| 기존 규칙 테스트 | PASS | 서버 실행 결과 55/55. 체크인 12, 겹침 31, 환불 12 |
| 기존 타입 검사 | PASS | `npm run typecheck`, 종료 코드 0. demo 서버·HTML은 기존 타입 검사 범위 밖 |
| 환불 경계 표시 | PASS | 브라우저에서 120분 전 3,000원, 바로 이후 1,500원; 30분 전 1,500원, 바로 이후 0원 확인 |
| tests 변경 여부 | PASS | 브라우저에서 HEAD 1761f77 대비 UNCHANGED, 변경 파일 0개 확인 |
| 화면·새로고침 | PASS | Codex 내장 브라우저에서 화면 열기, 표 8행 표시, 상태 새로고침 및 조회 시각 갱신 확인 |
| 테스트 변경·실패 상황의 UI | NOT_RUN | 테스트 파일 변경·실패 주입 없음 |
| 훅 차단 시연 | NOT_RUN | 이 화면에서는 Git 비교만 수행 |
| 토스 테스트 실연결 | NOT_RUN | 이 화면은 금액 계산만 수행 |

처음 파일 목록 조회의 복합 명령은 PreToolUse가 차단해 즉시 중단했다. 사용자 재개 지시 후 단순 읽기 명령으로 확인했다. 첫 서버 실행은 샌드박스의 포트 제한으로 실패했고 실행 권한 승인 후 시작했다. 처음 테스트 결과 판독은 Vitest JSON 리포터의 파일 출력 때문에 BLOCKED였으며, 명시적인 임시 결과 파일을 읽도록 수정한 후 실제 55개 통과를 확인했다.
