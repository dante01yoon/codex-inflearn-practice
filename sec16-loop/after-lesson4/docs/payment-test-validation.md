## 정책과 범위

- 카드만 허용하고 승인 상태 DONE만 결제 완료로 본다. 주문·결제 식별자·정수 3000원·KRW 대조.
- 일반 점유 종료 시각 10:10:00 미만에 처음 확인된 정상 승인은 예약 확정.
- 정확히 10:10:00과 이후 처음 확인된 승인은 예약 없이 3000원 전액 환불 요청. 성공 이벤트 이후에만 반환 완료 기록.
- 이미 처리한 승인·웹훅 반복과 전달 순서 변경에도 추가 예약·환불 없음.
- 웹훅 본문과 별도의 가짜 결제 조회 응답을 사용. 순수 함수 경계의 규칙·효과 요청 테스트이며 HTTP 수신, 진위 검증, 실제 결제 조회·환불 실행은 NOT_RUN.
- 비카드·불일치 승인 보상, 환불 실패·재시도와 나머지 C-04/C-07/C-09 정책은 이번 테스트로 확정하지 않음.
- 관련: US-05, AC-05-2~8, T-16·T-17·T-19의 순수 규칙 부분. 전체 T 작업과 서비스 완료 증거가 아님.
